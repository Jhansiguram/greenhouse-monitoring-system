# 🌱 Greenhouse Monitoring System

## Project Overview
The Greenhouse Monitoring System is an IoT-based project designed to monitor environmental conditions inside a greenhouse.

It monitors temperature, humidity, and light intensity using sensors. The system helps users observe greenhouse conditions and supports remote monitoring and control.

## Objectives
- Monitor temperature and humidity.
- Measure light intensity inside the greenhouse.
- Support remote monitoring and control.
- Record environmental data for observation.
- Help maintain suitable conditions for plant growth.

## Technologies Used
- Internet of Things (IoT)
- Temperature and Humidity Sensors
- Light Sensor
- Microcontroller
- Sensor Data Monitoring

## Project Features
- Real-time environmental monitoring.
- Temperature and humidity measurement.
- Light intensity monitoring.
- Remote monitoring and control.
- Environmental data logging.
